Setup Guide

Integration instructions for Safe Output Spring Boot Starter.

1. Maven Dependency

xml<dependency> <groupId>com.safeoutput</groupId> <artifactId>safe-output-spring-boot-starter</artifactId> <version>0.1.0-SNAPSHOT</version> </dependency>

2. application.yml (Minimal)

yamlsafe-output: rules: - name: maskRealName keys: [realName] type: CHINESE_NAME ignore: keys: [plainNote] report: enabled: true directory: ./reports file-prefix: mask-report interval-millis: 600000

3. log4j2.xml Configuration

Add %safeOutputMsg to your pattern layout to enable log masking.

xml<?xml version="1.0" encoding="UTF-8"?> <Configuration> <Appenders> <Console name="Console" target="SYSTEM_OUT"> <PatternLayout pattern="%d %safeOutputMsg%n"/> </Console> </Appenders> <Loggers> <Root level="info"> <AppenderRef ref="Console"/> </Root> </Loggers> </Configuration>

4. Custom MaskStrategy Bean

Register a custom strategy as a Spring Bean. It will be discovered automatically.

java@Component public class MyCustomStrategy implements MaskStrategy { @Override public String type() { return "MY_TYPE"; } @Override public String mask(String raw) { return raw.substring(0, 2) + "****"; } }

5. @Desensitize Annotation

Use on response DTO fields to declare masking type. Essential for ambiguous fields like name.

javapublic class CustomerResponse { @Desensitize(type = MaskTypes.CHINESE_NAME) private String name; private String mobile; // auto-detected }

6. Ignore Configuration

Exclude specific keys, API paths, or entire endpoints from masking while retaining statistics.

yamlsafe-output: ignore: keys: [debugInfo, plainNote] apis: - method: GET path: /api/public/health reason: public endpoint

7. Agent Skills (Preview)

Reserved integration points for AI-assisted operations:

  • response-risk-analysis-skill — Automated response risk assessment and governance recommendations
  • log-rule-config-suggestion-skill — Auto-discovery of unconfigured sensitive keys in log output
