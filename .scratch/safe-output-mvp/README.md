# Safe Output MVP Local Issues

This directory stores local Markdown issues for the Safe Output MVP.

## Workflow

- Source PRD: `docs/project/prd/safe-output-mvp-prd.md`
- Initial category: `enhancement`
- Initial state: `ready-for-agent`
- Triage labels: see `docs/agents/triage-labels.md`

## Issue Naming

Issue files use dependency-ordered numeric prefixes:

```text
0001-project-skeleton-and-starter-coordinates.md
0002-core-domain-model-and-strategy-spi.md
```

## Required Disclaimer

Every triage note or agent brief must start with:

```md
> *This was generated by AI during triage.*
```
