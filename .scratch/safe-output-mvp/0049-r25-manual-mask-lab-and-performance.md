## What to build

扩展 Demo 脱敏实验室，让接入方可以手动验证主动脱敏能力。实验室需要覆盖按类型脱敏、对象主动脱敏、强文本扫描、连续脱敏幂等和批量性能场景，并在前端展示输入、第一次脱敏、第二次脱敏、是否幂等、执行次数和耗时指标。

实验室必须调用 `SafeOutputMaskService`，不能绕过组件实现独立脱敏逻辑。

## Acceptance criteria

- [ ] 支持按类型标签输入值并执行主动脱敏。
- [ ] 支持对 Demo 业务对象执行主动对象脱敏。
- [ ] 支持对非结构化文本执行强文本扫描。
- [ ] 所有主动脱敏场景均展示第一次结果、第二次结果和幂等判断。
- [ ] 支持配置批量执行次数或输入规模，用于展示基础性能数据。
- [ ] 性能结果展示总耗时、平均耗时和执行次数。
- [ ] MANUAL 场景统计会随实验室调用更新。
- [ ] 页面说明主动脱敏与 Response 自动脱敏、Log 脱敏的场景差异。
- [ ] 响应和页面不保存敏感原文到报告中。
