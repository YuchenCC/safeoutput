## What to build

在 Dashboard starter 中提供通用脱敏实验室，支持按类型标签脱敏、对象脱敏和强文本扫描三类标准能力。实验室必须调用当前应用真实 `SafeOutputMaskService`、规则配置、注解、ignore、策略注册和强文本扫描能力，让接入方验证内置与自定义类型标签的运行效果。

每次实验固定执行两轮，返回脱敏结果、每轮耗时和二次脱敏稳定性；实验室调用计入 `MANUAL` 场景统计。响应不得返回用户输入原文。

## Acceptance criteria

- [ ] Dashboard 提供 POST API 执行按类型标签脱敏，支持内置和自定义类型标签。
- [ ] Dashboard 提供 POST API 执行对象脱敏，验证当前规则、注解和 ignore 行为。
- [ ] Dashboard 提供 POST API 执行强文本扫描，展示主动 strong scan 与 Response 自动脱敏的边界。
- [ ] 三类实验均固定执行两轮，返回每轮脱敏结果、`elapsedNanos` 和 `sameAsPrevious`。
- [ ] 实验室调用计入 `MANUAL` 场景统计。
- [ ] API 响应不返回原始输入，只返回脱敏结果、耗时、稳定性和必要规则摘要。
- [ ] 页面可以发起三类实验并展示两轮结果和耗时。
- [ ] 实验室不改变 `MaskRuleMatcher` 优先级，不把未知 type 自动改写成内置 `DEFAULT` 配置。
