## What to build

通过 starter 自动注册 Spring MVC `ResponseBodyAdvice`，在普通 JSON response 写出前执行输出侧脱敏。

## Acceptance criteria

- [ ] starter 引入后自动注册 response 脱敏 Advice。
- [ ] 全局开关和 response 场景开关生效。
- [ ] Controller 不改代码即可对 Bean、Map、List 响应脱敏。
- [ ] ResponseEntity body 可处理。
- [ ] 异常 fail-open，不影响接口返回。

## Test requirements

- 验证 `safe-output.enabled=false` 和 response 场景关闭。
