## What to build

把 Demo 报告能力升级为报告文件中心。用户可以导出脱敏统计 JSON 报告，查看当前 `safe-output.report.directory` 下有多少 JSON 报告文件，点击单个报告查看可视化报表。JSON 报告继续作为权威数据源，页面只基于聚合指标和脱敏 evidence 渲染。

报告文件读取能力必须限制在配置的报告目录内，只允许读取 JSON 报告快照，避免路径穿越和任意文件读取。

## Acceptance criteria

- [ ] 报告中心可以手动触发 JSON 报告导出。
- [ ] 报告中心可以列出报告目录下的 JSON 报告文件数量。
- [ ] 报告列表展示文件名、大小、修改时间和可查看入口。
- [ ] 可以读取指定 JSON 报告并渲染单报告视图。
- [ ] 单报告视图展示总量、Response/Log/Manual 场景分布和平均耗时。
- [ ] 单报告视图展示脱敏类型 Top 排名。
- [ ] 单报告视图展示高风险接口和 ignore 风险接口。
- [ ] 单报告视图展示日志规则建议、遗漏清单或治理建议。
- [ ] 报告文件读取接口拒绝路径穿越和非 JSON 报告读取。
- [ ] 报告中心不展示原始 response、完整日志或敏感命中值。
