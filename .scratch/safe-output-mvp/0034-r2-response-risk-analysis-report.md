## What to build

在定时报告或快照生成阶段读取 Response 聚合数据，使用规则型分析器生成接口风险画像和性能画像。敏感风险评分与性能警告分开展示，所有建议均为治理辅助信息，不自动改变运行配置。

## Acceptance criteria

- [x] 定时报告可生成 `responseRiskSummary`。
- [x] 定时报告可生成 `topRiskApis`。
- [x] 高风险接口可展示 `riskScore` 和 `riskLevel`。
- [x] 高风险接口可展示 `riskReasons`。
- [x] 高风险接口可展示 `governanceAdvice`。
- [x] 接口可展示 `performanceProfile`。
- [x] 性能警告与敏感风险评分分开展示。
- [x] ignore 接口在风险画像中标记 ignored 和 ignoreReason。
- [x] 报告不包含敏感原文、完整 response 或单次字段明细。
