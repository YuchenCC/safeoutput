## What to build

Response 脱敏后生成轻量事件并按接口维度聚合。事件和聚合只包含统计摘要，包括接口标识、耗时、脱敏字段数量、类型分布、规则命中、ignore 状态和失败信息，不保存原始 response、脱敏后 response、敏感原文或单次字段明细。

## Acceptance criteria

- [x] Response 脱敏后统计次数增加。
- [x] Response 脱敏耗时被记录。
- [x] 接口维度可聚合平均耗时、最大耗时和慢脱敏次数。
- [x] 接口维度可聚合脱敏字段数量和 type 分布。
- [x] 聚合 key 不直接使用原始 URI，应使用稳定接口标识。
- [x] ignore 接口仍进入风险画像基础数据，并标记 ignored 和 ignoreReason。
- [x] 事件和聚合不包含敏感原文、完整 response 或单次字段明细。
- [x] 在线链路只更新轻量聚合，不生成复杂分析结论。
