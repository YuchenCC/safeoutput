## What to build

新增 `safe-output-dashboard-spring-boot-starter` 可选附加包的最小可运行闭环。接入方引入该附加包后，Dashboard 默认不暴露任何 API 或页面；只有在 Spring MVC Web 应用中显式配置 `safe-output.dashboard.enabled=true` 时，才按配置前缀暴露本地 Dashboard 静态入口和 POST API 基础路由。

本切片只建立模块、配置属性、自动装配条件、路径前缀解析、静态页面壳层和最小健康信息，不迁入 Demo 业务域，也不实现完整治理数据。

## Acceptance criteria

- [ ] Maven reactor 包含新的 Dashboard starter 模块，保持 Java 8 与 Spring Boot 2.x 兼容。
- [ ] Dashboard starter 不依赖 `safe-output-demo`，不包含客户、订单、支付、工单、账户 mock 数据或小眼睛明文查看能力。
- [ ] 默认配置下引入 Dashboard starter 不注册 Dashboard API、Controller 或静态入口。
- [ ] `safe-output.dashboard.enabled=true` 且处于 Spring MVC Web 应用时，Dashboard 使用默认前缀 `/safe-output/dashboard` 暴露入口。
- [ ] `safe-output.dashboard.path-prefix` 可以调整静态入口和 API 前缀，API 统一位于 `{path-prefix}/api/...`。
- [ ] 非 Web 应用或非 Spring MVC 场景不暴露 Dashboard API。
- [ ] Dashboard 后端 API 基础路由只接受 POST；静态页面和静态资源可以通过 GET 加载。
- [ ] 失败或条件不满足时不影响宿主业务启动。
