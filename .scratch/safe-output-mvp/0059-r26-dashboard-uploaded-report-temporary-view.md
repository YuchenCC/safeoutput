## What to build

在 Dashboard starter 中提供单个 JSON 报告上传后的临时可视化查看能力。生产环境可以只启用 report、不启用 Dashboard；开发或运维人员把 JSON 报告带到受控测试环境后，通过 Dashboard 上传并查看聚合图表。

上传报告只做临时解析，不写入报告目录或其他持久化位置，不提供上传历史，也不展示 JSON 原文。

## Acceptance criteria

- [ ] Dashboard 提供 POST 上传 API，接受单个 Safe Output JSON 报告快照并返回可视化聚合模型。
- [ ] 上传报告校验扩展名、大小、JSON 结构和关键字段。
- [ ] 非 JSON 文件、超大文件、结构缺失或非法报告被拒绝，并返回可诊断错误。
- [ ] 上传报告不落盘，不进入报告目录列表，不产生上传历史。
- [ ] 上传报告视图复用单报告 dashboard 展示模型。
- [ ] 页面和 API 不展示 JSON 原文、原始 response、完整日志 message 或敏感命中值。
- [ ] 第一阶段不新增 `upload.enabled` 开关，不引入数据库、对象存储或清理策略。
