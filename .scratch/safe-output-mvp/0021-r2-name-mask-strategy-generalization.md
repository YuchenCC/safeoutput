## What to build

将内置姓名脱敏策略从传统中文姓名处理调整为通用姓名处理。命中姓名类型后，按首尾保留、中间脱敏的规则处理中文、少数民族姓名、英文名、中英混合姓名和常见分隔符姓名，但不扩大 `name` 等歧义字段的默认自动识别范围。

## Acceptance criteria

- [x] 空值和空字符串返回原值。
- [x] 长度为 1 的姓名脱敏为 `maskChar`。
- [x] 长度为 2 的姓名保留首字符，其余字符脱敏。
- [x] 长度大于等于 3 的姓名保留首尾字符，中间字符全部脱敏。
- [x] `张三` 脱敏为 `张*`，`王小明` 脱敏为 `王*明`。
- [x] `Alice`、`Michael Zhang`、`张 Michael` 等英文或中英混合姓名可稳定脱敏。
- [x] `name` 字段默认不因字段名本身被强制脱敏。
- [x] 配置 `realName` 或 `customerName` 后，可按姓名策略脱敏。
