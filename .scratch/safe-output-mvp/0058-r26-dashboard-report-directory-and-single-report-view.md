## What to build

在 Dashboard starter 中提供历史报告目录和单报告可视化。接入方启用 Dashboard 后，可以通过 POST API 列出当前 `safe-output.report.directory` 下的合法 JSON 报告快照，并选择一个报告渲染为聚合 Dashboard。

报告 JSON 继续作为 canonical report artifact；Dashboard 只负责读取合法报告并展示聚合结果。报告文件名必须通过请求体传递，不能放入 URL path 或 query string。
