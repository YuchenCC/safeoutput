## What to build

在 Dashboard starter 中提供历史报告目录和单报告可视化。接入方启用 Dashboard 后，可以通过 POST API 列出当前 `safe-output.report.directory` 下的合法 JSON 报告快照，并选择一个报告渲染为聚合 Dashboard。

报告 JSON 继续作为 canonical report artifact；Dashboard 只负责读取合法报告并展示聚合结果。报告文件名必须通过请求体传递，不能放入 URL path 或 query string。

## Acceptance criteria

- [ ] Dashboard 提供 POST API 列出报告目录下的合法 Safe Output JSON 报告文件。
- [ ] 报告列表展示文件名、大小、修改时间和可查看状态。
- [ ] Dashboard 提供 POST API 按请求体中的文件名读取单个报告并返回可视化聚合模型。
- [ ] 报告读取限制在 `safe-output.report.directory` 内，拒绝路径穿越、绝对路径和非报告文件。
- [ ] 单报告视图展示总量、场景分布、类型标签 Top、接口风险、ignore 风险、性能/异常摘要和日志规则建议。
- [ ] 页面和 API 不展示 JSON 原文、不展示原始 response、完整日志 message 或敏感命中值。
- [ ] Dashboard API 全部使用 POST；报告文件名不进入 URL。
