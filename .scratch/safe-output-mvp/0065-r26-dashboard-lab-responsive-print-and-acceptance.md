## What to build

完成 Dashboard starter 前端的最后体验收口：通用脱敏实验室布局、响应式堆叠、打印样式和人工视觉验收。

脱敏实验室采用三块并列或响应式堆叠的实验面板：按类型标签、对象脱敏、强文本扫描。每个面板展示输入控件、执行按钮、Round 1 / Round 2 脱敏结果、`elapsedNanos` 转换后的毫秒耗时和 `sameAsPrevious` 幂等判断。响应区域不得回显原始输入，只展示脱敏结果和必要规则摘要。

视觉风格沿用“白底业务后台 + 治理实证卡片”：浅色侧边栏、白色面板、细边框、蓝/青/绿/琥珀/红语义色、可扫描表格和浅底代码块。打印历史报告时隐藏侧边导航、刷新按钮、上传控件、Tab 控件和其他交互控件，保留报告标题、文件名、关键指标、表格化数据和风险/建议摘要。

## Acceptance criteria

- [ ] 脱敏实验室包含按类型标签、对象脱敏和强文本扫描三块实验面板。
- [ ] 每个实验面板展示输入控件、执行按钮、Round 1 / Round 2 脱敏结果、毫秒耗时和 `sameAsPrevious`。
- [ ] 实验结果区域不回显原始输入，只展示脱敏结果、耗时、稳定性和必要规则摘要。
- [ ] 桌面端 1920x1080 首屏可读，页面标题、主操作、关键指标和当前状态不需要滚动即可看到。
- [ ] 移动端或窄屏下左侧导航和三列实验面板可用，不出现文字溢出、控件重叠或布局横向破坏。
- [ ] 卡片圆角控制在 6-8px，颜色使用蓝/青/绿/琥珀/红语义色，避免深色指挥舱、大面积紫蓝渐变、粒子背景、玻璃拟态和营销页式 hero。
- [ ] 风险等级和置信度 badge 同时使用颜色和文字表达。
- [ ] 打印历史报告时隐藏侧边导航、刷新按钮、上传控件、Tab 控件和其他交互控件。
- [ ] 打印内容保留报告标题、文件名、关键指标、图表旁的表格化数据和风险/建议摘要。
- [ ] 全页面人工复核确认不展示原始 response、完整日志 message、上传报告 JSON 原文、敏感命中值或 Demo raw 明文字段。
