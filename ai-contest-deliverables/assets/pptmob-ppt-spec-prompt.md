# pptmob PPT 模板通用提示词规范

来源文件：`ai-contest-deliverables/assets/pptmob.pptx`

可复用资产：

- 标题左侧默认小蓝条：`ai-contest-deliverables/assets/pptmob-title-marker.svg`
- 默认页脚 logo：`ai-contest-deliverables/assets/pptmob-default-logo.png`；如生成工具支持 SVG，也可使用同目录 `pptmob-default-logo.svg`。

用途：作为通用 PPT 模板提示词，用于约束后续页面设计的标准画布、字体、色值、标题位置、版式和组件风格。

## 1. 标准画布

- 画布比例：16:9 宽屏。
- PPT 尺寸：`13.333 x 7.5 in`。
- 背景：纯白或接近纯白。
- 页面气质：浅色、克制、清晰、专业。
- 页面结构：左上主标题 + 中部主体内容。
- 内容密度：每页聚焦一个核心主题，避免堆叠过多信息块。
- 留白策略：页面左右和上下保留稳定留白，主体内容优先居中或按网格对齐。

## 2. 默认 Logo

- 默认 logo：使用兴业数金 logo，资源路径为 `ai-contest-deliverables/assets/pptmob-default-logo.png`；如生成工具支持 SVG，也可使用同目录 `pptmob-default-logo.svg`。
- 坐标来源：已从原始模板拆解并沉淀为本规范，后续生成时直接使用本节坐标和资产文件，不再依赖读取 `pptmob.pptx`。
- 摆放位置：右下角，`x=11.47in, y=6.91in`。
- Logo 尺寸：`w=1.28in, h=0.27in`。
- 边距参考：右边距约 `0.59in`，底边距约 `0.32in`。
- 使用原则：默认页脚 logo 保持原始比例、原始蓝色，不加描边、阴影、滤镜或重新着色；除封面等特殊页面另有设计需要外，内容页优先沿用该右下角位置。

## 3. 标题与版心

- 标题位置：左上，约 `x=0.84in, y=0.59in`。
- 标题占位：宽约 `11.65in`，高约 `0.71in`。
- 标题对齐：左对齐。
- 标题字号：约 `44pt`。
- 标题字体：优先使用 `Microsoft YaHei` / `微软雅黑`；也可使用主题字体 `DengXian Light`。
- 标题颜色：优先使用 `#141735`，也可在正文型页面使用 `#404040`。
- 标题左侧默认标识：使用 `ai-contest-deliverables/assets/pptmob-title-marker.svg`，视觉为竖向圆角小蓝条，填充色 `#4372C4`，无描边。
- 标识坐标：`x=0.70in, y=0.75in`。
- 标识尺寸：`w=0.10in, h=0.40in`。
- 标识与标题关系：小蓝条位于标题左侧，标题文本从 `x=0.84in` 开始，两者水平间距约 `0.04in`；小蓝条垂直居中对齐标题首行视觉中线。
- 使用原则：除封面、结束页或特殊大标题页另有明确设计外，所有按本规范生成的内容页标题左侧必须保留该小蓝条，不使用其他占位 logo、图标或装饰形状替代。
- 主体区域：建议从标题下方开始布局，避免主体元素贴近标题或页面边缘。

## 4. 字体规范

| 场景 | 字体 | 样式 | 参考字号 |
|---|---|---|---|
| 页面标题 | `Microsoft YaHei` / `微软雅黑` | Bold 或 Light | `40-44pt` |
| 强化内容 | `Microsoft YaHei` / `微软雅黑` | Bold | `28-32pt` |
| 正文内容 | `Microsoft YaHei Light` / `微软雅黑 Light` | Light | `18-24pt` |
| 辅助说明 | `Microsoft YaHei Light` / `微软雅黑 Light` | Light | `14-18pt` |
| 标签文字 | `Microsoft YaHei` / `微软雅黑` | Bold | `16-18pt` |

使用原则：

- 中文优先使用微软雅黑体系，避免混用过多字体。
- 标题和强化内容使用加粗样式建立层级。
- 正文和辅助说明使用 Light 字重，保持页面轻量。
- 英文、数字和符号应与中文保持同一视觉体系，不单独使用装饰性字体。
- 不使用负字距，不使用花体、手写体或过度压缩字体。

## 5. 色值规范

### 5.1 文字色

| 用途 | 色值 | 使用建议 |
|---|---|---|
| 主文本色 | `#141735` | 标题、一级观点、重要标签 |
| 正文深灰 | `#404040` | 正文、说明、大号内容文字 |
| 次文本色 | `#858A9E` | 辅助说明、图例、来源、页脚 |
| 弱化文本色 | `#C4C9D4` | 注释、低优先级信息、辅助标识 |
| 强调色 | `#B7393F` | 关键提醒、风险、局部强调 |
| 反白文字 | `#FFFFFF` | 深色块、蓝色标签块内文字 |

### 5.2 图形色

| 用途 | 色值 | 使用建议 |
|---|---|---|
| 主题蓝 | `#4371C4` | 主流程、主节点、标题标签、关键路径 |
| 辅助蓝 | `#507CAA` | 次级节点、模块分组、辅助流程 |
| 辅助青 | `#14A0C1` | 信息分组、数据节点、并列模块 |
| 辅助绿 | `#00CD99` | 正向状态、完成状态、验证结果 |

使用原则：

- 以 `#4371C4` 作为主视觉色。
- 蓝、青、绿用于建立信息层级，不要把页面做成单一色系。
- `#B7393F` 仅用于小面积强调，不作为大面积背景。
- 背景保持白色或近白色，避免大面积深色背景、复杂纹理和强渐变。

## 6. 图形与组件规范

- 圆环 / 色板图形：直径参考 `1.34in`，无描边，可用于颜色、状态或分类展示。
- 标签块：参考尺寸 `1.74in x 0.49in`，填充 `#4371C4`，无描边，文字使用白色加粗。
- 流程节点：优先使用实心矩形、圆形、圆环、细线连接，避免复杂 3D 或强阴影。
- 分组方式：优先使用留白、对齐、细线和轻量色块，不使用多层嵌套卡片。
- 线条：保持细、直、轻量，颜色可使用 `#C4C9D4`、`#858A9E` 或主题蓝的浅化版本。
- 图表：主数据使用主题蓝，辅助数据使用辅助蓝、辅助青、辅助绿；说明文字使用次文本色。
- 页面元素：标题、图形、标签、正文应有清晰对齐关系，避免漂浮和随机摆放。

## 7. 通用生成提示词

可直接复制以下提示词用于后续 PPT 页面设计：

```text
请按 pptmob 模板规范设计一页 16:9 PPT。

画布使用 13.333 x 7.5 in，背景为纯白或接近纯白。整体风格保持浅色、克制、清晰、专业，不使用大面积深色背景、复杂纹理、强渐变、夸张阴影或装饰性图形。

版式采用左上标题 + 中部主体内容。标题位于 x=0.84in、y=0.59in 附近，左对齐，字号约 44pt，颜色优先使用 #141735。标题左侧必须保留模板默认竖向圆角小蓝条，使用 ai-contest-deliverables/assets/pptmob-title-marker.svg，填充 #4372C4，无描边，坐标 x=0.70in、y=0.75in，尺寸 w=0.10in、h=0.40in。页面主体从标题下方展开，保持稳定留白和清晰对齐。

默认在右下角放置兴业数金 logo，使用 ai-contest-deliverables/assets/pptmob-default-logo.png。logo 坐标为 x=11.47in、y=6.91in，尺寸为 w=1.28in、h=0.27in。保持原始比例和原始蓝色，不加描边、阴影、滤镜或重新着色。

字体使用 Microsoft YaHei / 微软雅黑体系。标题和强化内容使用 Bold，正文和辅助说明使用 Microsoft YaHei Light / 微软雅黑 Light。正文不使用负字距，不使用花体、手写体或过度压缩字体。

文字颜色遵循：主文本 #141735，正文深灰 #404040，次文本 #858A9E，弱化文本 #C4C9D4，强调色 #B7393F，反白文字 #FFFFFF。

图形颜色遵循：主题蓝 #4371C4，辅助蓝 #507CAA，辅助青 #14A0C1，辅助绿 #00CD99。主流程、主节点和关键路径使用主题蓝，次级信息使用辅助蓝或辅助青，正向状态和完成状态使用辅助绿。

组件可使用圆环、实心矩形标签、轻量流程节点、细线连接和简洁图表。标签块使用 #4371C4 填充、白色加粗文字。避免卡片堆叠、嵌套卡片、过多描边、复杂阴影和随机摆放。

每页只表达一个核心主题，主体内容以一个主要图形、流程、图表、列表或证据对象承载，不要把多个复杂结构挤在同一页。
```

## 8. 输出检查清单

- 是否为 16:9 宽屏画布。
- 是否使用默认兴业数金 logo，并放置在右下角 `x=11.47in, y=6.91in, w=1.28in, h=0.27in`。
- 标题是否位于左上并保持左对齐。
- 标题左侧是否使用 `ai-contest-deliverables/assets/pptmob-title-marker.svg` 并放置为 `x=0.70in, y=0.75in, w=0.10in, h=0.40in, fill=#4372C4`。
- 字体是否统一使用微软雅黑体系。
- 主文本、正文、辅助文字和强调文字是否按色值规范区分。
- 图形主色是否使用 `#4371C4`，辅助色是否使用 `#507CAA`、`#14A0C1`、`#00CD99`。
- 背景是否保持白色或近白色。
- 页面是否只有一个核心主题。
- 主体内容是否对齐清晰、留白稳定。
- 是否避免了大面积深色背景、复杂渐变、夸张阴影和多层嵌套卡片。
