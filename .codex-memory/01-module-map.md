# 模块地图

| 模块 | 目录路径 | 主要职责 | 核心类 | 关键入口 | 依赖关系 | 后续优先查看 |
|---|---|---|---|---|---|---|
| 父工程 | `safe-output/` | Maven reactor、Java 8 / Boot 2.7.18 基线、checkstyle、verify 规则 | `pom.xml` | `mvn verify` | 管理所有子模块 | `safe-output/pom.xml`, `safe-output/README.md` |
| core | `safe-output/safe-output-core` | 脱敏类型、默认规则库、策略、规则匹配、注解解析、对象递归、主动脱敏基础 | `DefaultMaskRules`, `ObjectMasker`, `MaskRuleMatcher`, `SensitiveFieldResolver`, `BuiltInMaskStrategies`, `DefaultSafeOutputMaskService` | `SafeOutputMaskService`, `ObjectMasker.maskWithResult`, `DefaultMaskRules.all` | 无 Spring 依赖；被 starter/log4j2/report 依赖 | `DefaultMaskRules.java`, `ObjectMasker.java`, `MaskRuleMatcher.java`, `BuiltInMaskStrategies.java`, `StrongTextMasker.java` |
| log4j2 | `safe-output/safe-output-log4j2` | Log4j2 PatternConverter、日志 key-value/JSON-like 脱敏、regex fallback、日志规则线索采集、starter runtime bridge | `SafeOutputMessagePatternConverter`, `SafeOutputLogMessageMasker`, `SafeOutputLog4j2Runtime` | `%safeOutputMsg{...}` | 依赖 core；Log4j2 为 optional | `SafeOutputLogMessageMasker.java`, `SafeOutputMessagePatternConverter.java`, `SafeOutputLog4j2Runtime.java` |
| report | `safe-output/safe-output-report` | 指标采集、接口风险画像、性能画像、日志规则建议、JSON 报告导出 | `MaskMetricsCollector`, `ResponseRiskAnalyzer`, `MaskReportExporter`, `LogRuleSuggestionAnalyzer` | `MaskMetricsCollector.snapshot`, `MaskReportExporter.exportNow` | 依赖 core；被 starter/demo 依赖 | `MaskMetricsCollector.java`, `MaskReportExporter.java`, `ResponseRiskAnalyzer.java` |
| starter | `safe-output/safe-output-spring-boot-starter` | 对外集成入口、配置绑定、自动装配、MVC ResponseBodyAdvice、报告 Bean 创建 | `SafeOutputAutoConfiguration`, `SafeOutputMvcAutoConfiguration`, `SafeOutputProperties`, `SafeOutputResponseBodyAdvice`, `ApiIgnoreMatcher` | `META-INF/spring.factories` | 依赖 core/log4j2/report；Spring Boot autoconfigure/WebMVC optional | `SafeOutputAutoConfiguration.java`, `SafeOutputResponseBodyAdvice.java`, `SafeOutputProperties.java` |
| dashboard starter | `safe-output/safe-output-dashboard-spring-boot-starter` | 可选治理 Dashboard 自动装配、静态资源、POST API、报告目录安全读取、临时上传和通用脱敏实验室 | `SafeOutputDashboardAutoConfiguration`, `SafeOutputDashboardController`, `SafeOutputDashboardAssembler`, `SafeOutputDashboardReportFileStore`, `SafeOutputDashboardProperties` | `GET /safe-output/dashboard/index.html`, `POST /safe-output/dashboard/api/*` | 依赖 starter/report/core；Spring MVC Servlet Web optional；默认关闭 | `SafeOutputDashboardAutoConfiguration.java`, `SafeOutputDashboardController.java`, `SafeOutputDashboardAssembler.java`, `src/main/resources/safe-output-dashboard/*` |
| demo | `safe-output/safe-output-demo` | 端到端演示业务工作台、Response/Log/Manual/Report/接入说明，并启用可选 Dashboard starter | `DemoApplication`, `business/DemoBusinessController`, `business/DemoBusinessService`, `business/DemoBusinessDataSource`, `business/DemoBusinessLog`, `guide/DemoIntegrationGuideController`, `logs/DemoLogController`, `lab/DemoManualMaskController`, `report/DemoReportController`, `report/DemoReportFileStore`, `report/DemoReportDashboardAssembler`, `response/DemoResponseController` | `mvn -pl safe-output-demo -am spring-boot:run`, `/safe-output/dashboard/index.html` | 直接依赖 starter、dashboard starter、Spring Web、Log4j2 | `application.yml`, `log4j2.xml`, `static/index.html`, `static/js/views/*`, `business/*`, `report/*`, 各场景 controller |
| 测试 | 各模块 `src/test/java` | 核心契约、自动装配、日志转换、报告快照、Demo 集成验证 | `*Test`, `*IntegrationTest` | `mvn test` / `mvn verify` | 按模块依赖运行 | `SafeOutputResponseBodyAdviceIntegrationTest`, `DemoResponseIntegrationTest`, `SafeOutputLogMessageMaskerTest`, `MaskReportExporterTest` |
