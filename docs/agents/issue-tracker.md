# Issue Tracker

This repo uses local Markdown issues under `.scratch/safe-output-mvp/`.

## Rules

- Create one Markdown file per issue.
- Keep filenames stable and ordered by dependency, using a numeric prefix.
- Do not use GitHub Issues for this MVP unless this file is updated first.
- Every triage note or agent brief must start with:

```md
> *This was generated by AI during triage.*
```

## Issue Fields

Each issue should include:

- `category`: `bug` or `enhancement`
- `state`: one of `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`
- `source`: source PRD or planning document
- `wbs`: related WBS item or items
- `blocked_by`: issue filenames or `None`

## Source Documents

- Main PRD: `docs/project/prd/safe-output-mvp-prd.md`
- Requirements change log: `docs/project/prd/safe-output-requirements-change-log.md`
- Requirements clarifications: `docs/project/prd/safe-output-requirements-clarifications.md`
